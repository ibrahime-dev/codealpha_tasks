# CodeAlpha Full Stack Development Internship

Welcome to my CodeAlpha Full Stack Development Internship repository for the October 2026 batch.

This repository contains two full-stack web development projects built to practice and demonstrate my development skills.

## Projects

### 1. E-commerce Store

A full-stack online shopping application that allows users to browse products and manage their shopping carts.

**Features:**
- Browse product listings and view product details
- Search for products
- Add, remove, and update cart items
- User registration and login
- Place and manage orders

**Technologies:** React, Node.js, Express.js, MongoDB

### 2. Project Management Tool

A project management application for organizing projects and tracking tasks.

**Features:**
- Create and manage projects
- Create and assign tasks
- Update task statuses
- Add comments to tasks
- Organize tasks using a Kanban board

**Technologies:** React, Node.js, Express.js, MongoDB

## Tech Stack

- **Frontend:** React, CSS
- **Backend:** Node.js, Express.js
- **Database:** MongoDB
- **Version Control:** Git and GitHub
